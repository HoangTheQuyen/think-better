For Claude Code, GitHub Copilot, Antigravity & OpenCode

Make your AI think before it answers. Để AI suy nghĩ trước khi trả lời.

Structured thinking for your AI coding assistant: decide with frameworks, solve with root causes, code with evidence. One open-source CLI installs three skills and their slash commands: /decide, /solve and /code.

Tư duy có cấu trúc cho trợ lý AI lập trình: quyết định bằng framework, giải quyết vấn đề tận gốc, sửa code có bằng chứng. Một CLI mã nguồn mở cài ba skill cùng các lệnh slash: /decide, /solve và /code.

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/HoangTheQuyen/think-better/main/install.sh | sh think-better init --ai claude

Windows (PowerShell)

irm https://raw.githubusercontent.com/HoangTheQuyen/think-better/main/install.ps1 | iex think-better init --ai claude

Homebrew

brew tap HoangTheQuyen/think-better https://github.com/HoangTheQuyen/think-better brew install think-better

Why not just prompt? Vì sao không chỉ viết prompt?

Ask any AI "should we use Postgres or MongoDB?" and you get a tidy pros-and-cons list. The skills add what a prompt alone does not.

Hỏi AI bất kỳ "nên dùng Postgres hay MongoDB?" và bạn nhận được danh sách ưu/nhược điểm gọn gàng. Các skill bổ sung những gì một prompt đơn thuần không có.

🧭

Structured stepsQuy trình có cấu trúc

Every request runs through a fixed method: 7 steps for problems and code, a decision plan for choices. The AI does not jump from symptom to fix.

Mọi yêu cầu đi qua một phương pháp cố định: 7 bước cho vấn đề và code, kế hoạch quyết định cho các lựa chọn. AI không nhảy thẳng từ triệu chứng sang cách sửa.

🚦

GatesCổng kiểm tra

/code does not move on without evidence: a failing test before the fix, your project's own test, lint and build output after it.

/code chỉ qua bước khi có bằng chứng: test fail trước khi sửa, kết quả test, lint, build của chính project sau khi sửa.

📚

A knowledge baseKho kiến thức

323 knowledge records searched locally with BM25: make-decision · 63 records, problem-solving-pro · 111 records, code-solving · 149 records. Frameworks, cognitive biases with remedies, criteria templates and 44 common error messages go into the answer.

323 bản ghi kiến thức được tìm ngay trên máy bằng BM25: make-decision · 63 bản ghi, problem-solving-pro · 111 bản ghi, code-solving · 149 bản ghi. Framework, thiên kiến nhận thức kèm cách khắc phục, mẫu tiêu chí và 44 thông báo lỗi hay gặp được đưa vào câu trả lời.

💾

Saved, resumable workspacesWorkspace lưu lại, làm tiếp được

Say "save step-by-step" and the work is written to Markdown files in your project. /solve.resume, /decide.resume or /code.resume continues at the first open step in a later session.

Nói "lưu từng bước" và công việc được ghi thành file Markdown trong project. /solve.resume, /decide.resume hoặc /code.resume làm tiếp từ bước còn dang dở ở phiên sau.

🔒

Runs locallyChạy trên máy bạn

One Go binary copies Markdown, CSV and Python files into your project. The scripts need only Python 3's standard library: no network calls, no accounts, no API keys.

Một chương trình Go chép các file Markdown, CSV và Python vào project. Script chỉ cần thư viện chuẩn của Python 3: không gọi mạng, không tài khoản, không API key.

🇻🇳

English and VietnameseTiếng Anh và tiếng Việt

Requests work in both languages, Vietnamese with or without accents ("Nên chọn React hay Vue?"). The AI answers in your language.

Yêu cầu bằng cả hai ngôn ngữ, tiếng Việt có dấu hay không dấu đều được ("Nen chon React hay Vue?"). AI trả lời bằng ngôn ngữ của bạn.

How it worksCách hoạt động

From your request to a structured plan, on your machine.

Từ yêu cầu của bạn đến một kế hoạch có cấu trúc, ngay trên máy bạn.

  1. You askBạn hỏi

    A slash command like /solve.deep, or plain words where your AI tool loads skills.

    Một lệnh slash như /solve.deep, hoặc lời bình thường nếu công cụ AI tự nạp skill.

  2. The skill runsSkill chạy

    The AI runs the skill's Python script with your request on stdin. No network, no API keys.

    AI chạy script Python của skill, yêu cầu được truyền qua stdin. Không cần mạng hay API key.

  3. Search and classifyTìm và phân loại

    BM25 search over the knowledge base; the request is classified (decision type, problem type, coding task); /code also reads your project.

    Tìm BM25 trong kho kiến thức; phân loại yêu cầu (loại quyết định, loại vấn đề, loại việc code); /code còn đọc project của bạn.

  4. A plan with next stepsKế hoạch và bước tiếp theo

    Framework, steps and gates, bias warnings, a checklist and the next commands; saved as a workspace if you ask.

    Framework, các bước và cổng kiểm tra, cảnh báo thiên kiến, checklist và lệnh tiếp theo; lưu thành workspace nếu bạn muốn.

Four depth levelsBốn mức độ sâu

  • QuickThe essentials on one screenNhững điểm chính trong một màn hình
  • StandardThe full plan (default)Kế hoạch đầy đủ (mặc định)
  • DeepAlternatives, pre-mortem, pitfallsPhương án thay thế, pre-mortem, lỗi hay gặp
  • ExecutiveRecommendation first, risks, decision neededKhuyến nghị trước, rủi ro, quyết định cần đưa ra

Install in a minuteCài đặt trong một phút

STEP 1BƯỚC 1

Install the CLICài CLI

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/HoangTheQuyen/think-better/main/install.sh | sh
# Windows (PowerShell)
irm https://raw.githubusercontent.com/HoangTheQuyen/think-better/main/install.ps1 | iex
# Homebrew
brew tap HoangTheQuyen/think-better https://github.com/HoangTheQuyen/think-better
brew install think-better
# Scoop
scoop bucket add think-better https://github.com/HoangTheQuyen/think-better
scoop install think-better
# Go 1.25+
go install github.com/HoangTheQuyen/think-better/cmd/think-better@latest

STEP 2BƯỚC 2

Add the skills to your projectThêm skill vào project

# in your project root
think-better init --ai claude
think-better init --ai copilot
think-better init --ai antigravity
think-better init --ai opencode
# once for every project
think-better init --ai claude --global
# later, after upgrading
think-better update
# files you edited: see their .new versions
think-better diff

       the pricing change
